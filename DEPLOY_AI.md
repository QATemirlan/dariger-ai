# Подключение ИИ-ассистента к demo-кабинету

Сайт на GitHub Pages — статический, «думать» не умеет. Поэтому ассистент работает через
сервер-«мост» (`app/api/chat/route.ts`): браузер отправляет вопрос мосту, мост вызывает
ИИ и возвращает ответ. **Ключ ИИ хранится только на сервере — посетители его не видят.**

Без моста и ключа демо продолжает работать со старыми заготовленными ответами (ничего не ломается).

## Что нужно: 3 шага

### Шаг 1. Получить API-ключ ИИ

Любой OpenAI-совместимый провайдер:

| Провайдер | Где взять ключ | `AI_BASE_URL` | `AI_MODEL` (пример) |
|---|---|---|---|
| GLM (Zhipu) | https://bigmodel.cn → API Keys | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` (есть бесплатный) |
| OpenAI | https://platform.openai.com → API Keys | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | https://platform.deepseek.com | `https://api.deepseek.com/v1` | `deepseek-chat` |

### Шаг 2. Задеплоить мост на хостинг

#### Вариант А — SmarterASP.NET (у вас уже есть аккаунт, 60 дней бесплатно)
1. В панели SmarterASP создайте сайт типа **Node.js**.
2. Привяжите GitHub-репозиторий `QATemirlan/dariger-ai` (они умеют собирать и деплоить автоматически).
3. В настройках сайта добавьте переменные окружения (Application Settings / Environment Variables):
   - `AI_BASE_URL` — из таблицы выше
   - `AI_API_KEY` — ваш ключ
   - `AI_MODEL` — из таблицы выше
4. Стартовая команда: `npm run start` (порт задаёт хостинг через `PORT`).
5. После деплоя вы получите адрес вида `http://логин.smarterasp.net` — это адрес моста.

#### Вариант Б — Vercel (бесплатен навсегда для такого трафика, как альтернатива)
1. https://vercel.com → Import Git Repository → выберите репозиторий.
2. Settings → Environment Variables: те же три переменные (`AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`).
3. Deploy → адрес вида `https://dariger-ai-xxx.vercel.app`.

### Шаг 3. Сообщить сайту адрес моста
В настройках GitHub Pages (или локально в `.env.local`, он не попадает в git):
```
NEXT_PUBLIC_AI_URL=https://ваш-адрес-моста
```
После этого чат в demo начнёт отвечать настоящим ИИ.

## Локальное тестирование (не публикуя ключ)
1. Создайте `.env.local` в корне проекта (он в `.gitignore`):
   ```
   AI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
   AI_API_KEY=ваш_ключ
   AI_MODEL=glm-4-flash
   ```
2. Перезапустите `npm run dev` — переменные подхватятся.
3. Откройте http://localhost:3000/demo и спросите ассистента что-нибудь.

## Как это работает
- Чат шлёт POST `/api/chat` с историей сообщений.
- Мост добавляет системный промпт «клинический ассистент врача РК» + контекст демо-пациента
  (Ибрагимова: жалобы, АД, терапия) и вызывает провайдера.
- Rate-limit: 30 запросов с IP за 5 минут.
- Ошибка/нет ключа → JSON `{reply, mode: "fallback"}` с прежним заготовленным ответом.
- Оффлайн-история (первые 6 приветственных реплик) остаётся локальной.

## Расходы
GLM `glm-4-flash` — бесплатная модель; OpenAI `gpt-4o-mini` ≈ $0.15–0.6 за миллион токенов
(на демо-трафике — центы в месяц). Хостинг: SmarterASP триал 60 дней → $2.95/мес, Vercel — 0 ₸.
